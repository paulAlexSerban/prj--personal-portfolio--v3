## Snippet

```typescript
export function debounce<T extends (...args: unknown[]) => void>(fn: T, ms: number): T {
    let timer: ReturnType<typeof setTimeout> | undefined;
    return ((...args: Parameters<T>) => {
        clearTimeout(timer);
        timer = setTimeout(() => fn(...args), ms);
    }) as T;
}
```

## Notes

Fixture only — clears prior timer, schedules a new call after `ms`. Used so snippet listing and detail pages render from SQLite-backed content.
