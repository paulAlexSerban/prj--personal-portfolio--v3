## Problem

Live content is large and private. The `test.*` environment needs predictable fixtures so CI can validate rendering without cloning production content.

## Approach

Author a minimal MDX/JSON tree under `content/test/content/publish/` that covers every ingest mapping the pipeline supports.

## Outcome

Test deploys ingest fixtures via `CONTENT_DIR`; production and GitHub Pages keep using `content/live`.
