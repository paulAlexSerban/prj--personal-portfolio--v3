## Key Ideas

Architecture is a continuous decision process. Three primitives show up everywhere:

1. **Components** - units of computation with an interface
2. **Connectors** - how components communicate (sync HTTP, async queues)
3. **Configurations** - how components and connectors are assembled

```typescript
type Component = { name: string; interface: string[] };
type Connector = 'http' | 'queue' | 'function-call';

const example: Component = {
    name: 'OrderService',
    interface: ['placeOrder', 'cancelOrder'],
};
```

## Trade-offs

- Premature microservices add operational cost without clear benefit
- Documented ADRs keep the _why_ after the _how_ has been rewritten
- High cohesion and low coupling remain the evaluation lens
