## Extracted Topic

Drawing correct module boundaries using coupling/cohesion analysis - the load-bearing skill exercised by the fixture post.

## The Vital 20%

- Bounded Context identification as a primary cut heuristic
- Coupling vs. cohesion as the evaluation lens
- Sync vs. async connector choice
- Dependency direction / interface-first design
- Documenting decisions with ADRs

## 20-Hour Plan

### Session 1 - Name components and connectors in a familiar codebase

- **Core concept(s):** Architectural vocabulary
- **Hands-on task:** List 5 components and classify each connector as sync or async.
- **15-min review:** Can you define high cohesion / low coupling without the word "modular"?

### Session 2 - Write one ADR for a real boundary decision

- **Core concept(s):** Documented architectural reasoning
- **Hands-on task:** Use Status / Context / Decision Drivers / Options / Decision / Consequences.
- **15-min review:** Which rejected option had the strongest counter-argument?

## What This Plan Deliberately Skips

Container orchestration details and CAP theorem proofs - downstream of getting boundaries right.
